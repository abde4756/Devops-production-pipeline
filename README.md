# DevOps Production Pipeline

This project demonstrates a simple DevOps production pipeline using Python and Docker.

The goal of the project is to simulate a real-world deployment workflow where an application is containerized and prepared for production environments.

## Overview

The project focuses on building a reproducible environment for running applications using containerization. It shows how DevOps practices can simplify development, testing, and deployment.

## Features

- Containerized application using Docker
- Python-based service
- Reproducible development environment
- Simple deployment workflow
- DevOps-oriented project structure

## Technologies

- Python
- Docker
- Linux
- Git
